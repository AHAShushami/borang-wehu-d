Tetapan URL Google Apps Script (WEHU_D)

Untuk membolehkan penghantaran terus daripada GitHub Pages ke Google Sheet WEHU_D:

  1. Buka Google Sheet WEHU_D → Extensions > Apps Script.
  2. Salin kod daripada fail Code.gs dalam projek ini dan tampal ke dalam editor Apps Script.
  3. Klik Deploy > New deployment (Jenis: Web app, Execute as: Me, Who has access: Anyone).
